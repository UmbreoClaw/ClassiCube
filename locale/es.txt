# ClassiCube Spanish (Español) locale file
#
# Format: <English text>=<translated text>
#   - The text before the first '=' is the original English UI text (the key)
#   - The text after it is the translation shown in game
#   - Lines starting with '#' and blank lines are ignored
#
# This file is UTF-8 encoded. ClassiCube decodes it to its internal CP437
#   character set, so accented Spanish letters (á é í ó ú ñ ¿ ¡ ü) are supported.
#
# To use this language, set "language=es" in options.txt (or copy this file to
#   "locale/es.txt" next to the game and the launcher will pick it up at startup)
#
# Only user interface text set through the translatable helpers is translated;
#   any English text without a matching line below is shown unchanged.
